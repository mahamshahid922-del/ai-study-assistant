# AI-Powered Study Assistant

Final project for the Building AI course

## Summary
A smart study assistant designed to help engineering and computer science students summarize lecture notes, generate practice quiz questions, and break down complex technical concepts like Digital Logic Design or Calculus.

## Background
Students often struggle to find quick, structured practice problems tailored to their exact course syllabus before exams. Finding reliable summaries or step-by-step solutions manually takes a lot of time. This project aims to bridge that gap using AI-driven study tools.

* Lack of syllabus-aligned practice questions
* Time-consuming manual note summarization
* Difficulty in verifying step-by-step solutions for technical subjects

## Data Sources and AI Methods
* **Data Sources:** Textbooks, lecture slide transcripts, and student notes.
* **AI Techniques:** Natural Language Processing (NLP) using Large Language Models (LLMs) to process text, generate flashcards, and extract key concepts.

| Element | Description |
| ------- | ----------- |
| Input | PDF lecture slides and text notes |
| Model | NLP transformer models for summarization |
| Output | Concise notes, flashcards, and step-by-step answers |

## How is it used?
Students upload their lecture slides or notes in PDF format. The system processes the document and generates:
1. Concise topic summaries
2. Step-by-step practice problems
3. Interactive Q&A support for specific exercises

## Challenges
* Ensuring high accuracy for complex mathematical equations and logical circuit derivations.
* Avoiding hallucinated or incorrect solutions for technical engineering problems.

## What Next?
* Adding OCR support to scan handwritten notes.
* Integrating interactive diagram generation for digital logic circuits and database ER schemas.
